Live endpoint

A remote MCP server over Streamable HTTP. Everything is free. Discovery and every keyless connector work immediately; keyed connectors are bring-your-own-key — set the env var and they go live (until then they return HTTP 503 with a link to get a key).

Bring your own key

Everything here is free. Most sources are keyless and work the moment you connect. A few wrap government APIs that require a free API key — you provide your own, set as an environment variable on your deployment. The gateway ships no master keys and never sees yours after it's set. Ask the agent to call auth_status to see which keys are set and which are still missing.

Design principles

Raw passthrough

Connectors forward queries to the upstream API verbatim and return the response unmodified — no field renaming, no reshaping.

LLM-optimized docs

Each tool description teaches an agent the endpoint patterns, parameter formats, worked examples, and the common errors to avoid.

Bring-your-own-key

No master keys shipped. Keyless sources work instantly; keyed sources read a free API key from your own environment, so you own the quota and the ToS.

Connect in 30 seconds

Claude Desktop

Bridges stdio → remote via mcp-remote. Add to claude_desktop_config.json:

{
  "mcpServers": {
    "govdata": {
      "command": "npx",
      "args": ["-y", "mcp-remote",
        "https://govdata-mcp.vercel.app/api/mcp"]
    }
  }
}

Cursor

Speaks Streamable HTTP directly. Add to .cursor/mcp.json:

{
  "mcpServers": {
    "govdata": {
      "url":
        "https://govdata-mcp.vercel.app/api/mcp"
    }
  }
}

Any MCP client that supports Streamable HTTP can connect to the URL directly.
