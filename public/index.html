Live endpoint

A remote MCP server over Streamable HTTP. No auth, no API key — discovery and the free connectors work immediately; premium connectors return HTTP 402 until billing is enabled.

https://govdata-mcp.vercel.app/api/mcp

Three tiers

Tier 1 — free

Discovery

One discover_data_sources tool returns the full directory: every source, its tier, upstream base URL, schema notes, and a native example query.

$0

Tier 1.5 — free

Free connectors

Unmetered raw-passthrough connectors. Queries forward to the upstream API verbatim and return the unmodified response. No payment.

$0

Tier 2 — premium

Metered connectors

HTTP-402-gated connectors with server-held credentials, billed as micro-fees per call. Pay only for what an agent actually queries.

402 · micro-fee / call

Design principles

Raw passthrough

Connectors forward queries to the upstream API verbatim and return the response unmodified — no field renaming, no reshaping.

LLM-optimized docs

Each tool description teaches an agent the endpoint patterns, parameter formats, worked examples, and the common errors to avoid.

Zero-provisioning credentials

Master API keys live on the server. Agents query immediately and never see, hold, or provision a key.

Connect in 30 seconds

Claude Desktop

Bridges stdio → remote via mcp-remote. Add to claude_desktop_config.json:

{
  "mcpServers": {
    "govdata": {
      "command": "npx",
      "args": ["-y", "mcp-remote",
        "https://govdata-mcp.vercel.app/api/mcp"]
    }
  }
}

Cursor

Speaks Streamable HTTP directly. Add to .cursor/mcp.json:

{
  "mcpServers": {
    "govdata": {
      "url":
        "https://govdata-mcp.vercel.app/api/mcp"
    }
  }
}

Any MCP client that supports Streamable HTTP can connect to the URL directly.
